## Root cause
1. **(Primary) LLM quota exhausted.** All discover (gemini-3.5-flash) and enrich (gemini-3.1-pro-preview) calls go through `EMERGENT_LLM_KEY` (present, not empty) and return HTTP **429 "You exceeded your current quota, please check your plan and billing details"** / "No deployments available". With no AI output, discovery adds 0 and enrichment researches 0 → UI counters frozen (`last_stats.added=0, enriched=0`).
2. **(Secondary, code bug — verified in sandbox) Quota detection misses this error class.** `core/prospector.py` line 101: `_QUOTA_MARKERS = ("spend limit","budget","insufficient balance","insufficient_quota")`. The real errors ("exceeded your current quota", "RateLimitError", "429", "No deployments available") match **none** of these (confirmed: both live strings → `False`). Consequences:
   - `ai_blocked_at`/`ai_blocked_reason` are never set (hence absent in prospect_lock), so no UI "AI blocked" banner and no back-off — the worker keeps hammering the exhausted key and marking brands `failed` (1,695 and climbing).
   - The requeue regex in `routes/prospecting.py` (~line 367: `spend limit|budget|insufficient balance|insufficient_quota`) also won't match, so **these 1,695 quota-failed brands will NOT auto-requeue** even after the key is topped up — they'll need a manual requeue or a broadened regex.

## Fixes
- **User (Emergent LLM credits):** Top up / raise the budget on `EMERGENT_LLM_KEY` (the Gemini quota behind it is exhausted — upstream says "check your plan and billing details"). Once restored, discovery/enrichment resume automatically on the next 15-min cron.
- **Code (E1):** Broaden quota detection in `core/prospector.py` `_QUOTA_MARKERS` (and the requeue regex in `routes/prospecting.py`) to include `exceeded your current quota`, `ratelimiterror`, `429`, `resource_exhausted`, `no deployments available`. This makes the circuit breaker trip (set `ai_blocked_at`/reason, raise `AiCreditsOut`, stop hammering) and lets the 1,695 quota-failed brands be re-queued after credits return. Then trigger a requeue of the quota-failed prospects.
